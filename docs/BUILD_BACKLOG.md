# PlayScout 开发任务清单

Codex 按编号顺序执行。每个 Epic 完成后先运行该阶段测试，再进入下一阶段。

## E0：项目初始化

- [ ] E0-01 新建 Next.js App Router + TypeScript 项目。
- [ ] E0-02 配置 Tailwind、ESLint、格式化、测试框架和路径别名。
- [ ] E0-03 建立 `.env.example`、README 和本地启动命令。
- [ ] E0-04 配置 PostgreSQL、Prisma 和第一份迁移。
- [ ] E0-05 建立全局颜色、排版、间距、圆角和阴影令牌。
- [ ] E0-06 将原型素材放入受控的 demo/seed 目录并标明仅限原型。

验收：空数据库可以一条命令迁移和种子化；首页骨架可以启动；lint、类型检查和测试命令可运行。

## E1：核心数据与种子

- [ ] E1-01 实现 games、companies、platforms、genres、tags。
- [ ] E1-02 实现 store_listings、game_versions、source_records、assets。
- [ ] E1-03 实现 content_items、content_games、content_sources、revisions。
- [ ] E1-04 实现 ranking_snapshots、ranking_entries、heat_metrics。
- [ ] E1-05 实现 videos、redeem_codes、game_events。
- [ ] E1-06 实现 submissions、corrections、jobs、audit_logs、redirects。
- [ ] E1-07 为 12 个旗舰游戏和 50 个演示游戏编写可重复运行的 seed。

验收：关系、唯一键和索引完成；重复 seed 不产生重复实体；可以查询一个游戏的全部关联信息。

## E2：公共布局与首页

- [ ] E2-01 Header、趋势条、主导航、地区选择和 Footer。
- [ ] E2-02 统一卡片、标签、时间、来源和验证状态组件。
- [ ] E2-03 实现首页三栏首屏：主专题、今日更新、实时榜单。
- [ ] E2-04 实现热门游戏、新游、更新攻略、视频、兑换码、分类和社区模块。
- [ ] E2-05 实现榜单标签切换和地区筛选，并同步 URL 查询参数。
- [ ] E2-06 完成移动端导航、首屏和横向游戏轨道。
- [ ] E2-07 按 UI 规范完成组件的 loading、empty、error、stale、hover 和 focus 状态。
- [ ] E2-08 检查所有一级导航和 View all 进入独立页面，禁止 `#` 占位链接。

验收：首页使用数据库数据；无数据时有空状态；交互可键盘操作；桌面和移动截图通过视觉检查；内容密度达到页面矩阵基线。

## E3：游戏库与游戏中心

- [ ] E3-01 `/games` 筛选、排序、分页和稳定 URL。
- [ ] E3-02 `/games/[slug]` 头部、商店信息和版本信息。
- [ ] E3-03 Start here、攻略分组、排名趋势和活动模块。
- [ ] E3-04 视频、兑换码、玩家技巧和 Trust 模块。
- [ ] E3-05 实现游戏中心索引门槛和 noindex 逻辑。
- [ ] E3-06 实现别名解析和游戏合并 301。

验收：游戏库筛选可分享；游戏中心关系正确；未达门槛页面不会被索引。

## E4：内容频道与详情页

- [ ] E4-01 Guides、News、Reviews、Videos、Codes 频道页。
- [ ] E4-02 通用内容详情页和各内容类型扩展区块。
- [ ] E4-03 目录、面包屑、作者、来源、版本和最后验证组件。
- [ ] E4-04 相关阅读与前置/下一步攻略内链。
- [ ] E4-05 兑换码复制、状态和过期历史。
- [ ] E4-06 视频具体链接、嵌入状态和关键时间点。

验收：所有内容类型能独立发布；页面不出现无来源事实；具体视频链接可用。

## E5：榜单与热度

- [ ] E5-01 `/rankings` 总览和榜单详情。
- [ ] E5-02 平台、国家、分类、类型和时间窗口筛选。
- [ ] E5-03 排名变化、最高排名、上榜时长和趋势图。
- [ ] E5-04 综合热度计算、置信度和算法版本。
- [ ] E5-05 来源、更新时间和榜单方法说明。
- [ ] E5-06 排名异常检测与后台队列。

验收：同一快照不重复；趋势来自历史快照；综合热度可解释并有单元测试。

## E6：采集与任务

- [ ] E6-01 SourceAdapter 接口、任务执行器和重试机制。
- [ ] E6-02 实现 `ChartProviderAdapter`；生产连接获授权的榜单服务，开发环境连接带 `is_demo` 标记的固定适配器。
- [ ] E6-03 实现 `AppleSearchAdapter` 游戏元数据导入，并保留 Android/Steam 适配器接口。
- [ ] E6-04 实现 YouTube 具体视频导入和嵌入状态检查。
- [ ] E6-05 实现官方公告或 RSS 来源。
- [ ] E6-06 实现差异检测、实体匹配和人工审核队列。
- [ ] E6-07 实现内容、兑换码、活动和视频过期扫描。

验收：任务幂等；失败可重试；原始记录可追溯；异常值不覆盖可信数据。

## E7：搜索与后台

- [ ] E7-01 游戏名称、别名和内容全文搜索。
- [ ] E7-02 搜索分组、筛选、空状态和 noindex。
- [ ] E7-03 后台身份认证和角色权限。
- [ ] E7-04 Dashboard、Games、Content、Rankings、Codes、Events、Videos。
- [ ] E7-05 投稿、纠错、来源与异常任务页面。
- [ ] E7-06 发布、复核、过期、归档和审计日志。

验收：编辑可以从草稿发布内容；管理员可以处理异常和重试任务；所有写操作有审计记录。

## E8：SEO、分析与上线质量

- [ ] E8-01 metadata 模板、canonical、robots 和分片 sitemap。
- [ ] E8-02 Game、Article、VideoObject、BreadcrumbList 结构化数据。
- [ ] E8-03 内链规则与孤立页面检查。
- [ ] E8-04 分析事件和基础增长看板。
- [ ] E8-05 图片、字体、缓存和数据库查询优化。
- [ ] E8-06 键盘、焦点、对比度、标签和屏幕阅读器检查。
- [ ] E8-07 核心流程端到端测试、404/500 页面和错误监控。
- [ ] E8-08 生产迁移、备份、回滚和上线检查单。

验收：实施规格第 19 节全部通过后才进入上线候选状态。
