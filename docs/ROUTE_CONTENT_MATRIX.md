# PlayScout 页面与跳转矩阵

本文件用于确保网站拥有完整页面体系，避免所有入口重复跳转首页或同一个游戏页。

## 1. 一级页面内容量

| 页面 | 首期服务端内容量 | 必须具备的下一跳 |
|---|---:|---|
| 首页 | 30–45 个内容入口 | 游戏中心、榜单、新游、攻略、新闻、视频、兑换码 |
| 游戏库 | 每页 24 款游戏 | 游戏中心、平台页、分类页、分页 |
| 榜单总览 | 6 个榜单预览，每个 5–10 款 | 榜单详情、游戏中心、方法页 |
| 榜单详情 | 每页 50 款 | 游戏中心、历史趋势、相关攻略 |
| 最新游戏 | 每页 20 款 | 游戏中心、发布日期、商店页 |
| 攻略频道 | 每页 20 篇 | 攻略详情、游戏中心、分类页 |
| 新闻频道 | 每页 25 篇 | 新闻详情、游戏中心、专题页 |
| 视频频道 | 每页 18 个 | 具体视频、游戏中心、相关攻略 |
| 兑换码频道 | 每页 20 款 | 单游戏兑换码、游戏中心 |
| 评测频道 | 每页 20 篇 | 评测详情、游戏中心、最佳游戏合集 |

## 2. 游戏中心内容量

旗舰游戏中心上线时至少包含：1 个完整游戏概览、1 条新手路线、8 篇攻略、1 个 Tier List、3 个具体视频、兑换码页、3 个活动、7 天榜单趋势、4 款相关游戏，以及来源、作者和最后验证记录。

普通游戏中心上线门槛按 `IMPLEMENTATION_SPEC.md` 执行。

## 3. 主要用户路径

### 3.1 从榜单发现游戏

```text
首页实时榜单 → 榜单详情 → 游戏中心 → Start here → 具体新手攻略 → 相关工具或视频
```

### 3.2 查询兑换码

```text
搜索/首页兑换码 → 兑换码频道 → 单游戏兑换码页 → 复制兑换码 → 游戏中心活动或新手攻略
```

### 3.3 查找新游戏

```text
首页 New & upcoming → 最新游戏页 → 上线日期/平台筛选 → 游戏中心 → 评测或商店链接
```

### 3.4 通过搜索解决问题

```text
全局搜索 → 按 Games/Guides/Codes/Videos 分组结果 → 攻略详情 → 游戏中心 → 下一步攻略
```

### 3.5 视频学习

```text
视频频道 → 站内视频摘要页或具体外部视频 → 文字步骤 → 游戏中心 → 相关攻略
```

### 3.6 新闻转化为长期流量

```text
新闻频道 → 新闻详情 → 对应游戏中心 → 版本变化说明 → 新手/活动攻略
```

## 4. 全局导航目标

| 导航入口 | 目标路由 | 允许跳回首页 |
|---|---|---|
| Logo | `/` | 是 |
| Games | `/games` | 否 |
| Rankings | `/rankings` | 否 |
| Guides | `/guides` | 否 |
| News | `/news` | 否 |
| Videos | `/videos` | 否 |
| Codes | `/codes` | 否 |
| New releases | `/new-games` | 否 |
| Search | `/search?q=` | 否 |

一级导航不得使用 `#` 占位链接。频道卡片必须进入具体详情页、游戏中心或有真实筛选状态的列表页。

## 5. 页面间内链最低要求

- 首页模块的 View all 必须进入相应频道。
- 榜单中的每款游戏进入自己的游戏中心。
- 游戏中心的攻略卡进入具体攻略详情。
- 攻略页至少包含 3 个相关内容和 1 个游戏中心入口。
- 新闻页至少链接一个游戏中心或主题页。
- 视频卡链接具体视频，并同时提供游戏中心入口。
- 兑换码页链接游戏中心和兑换方法。
- 每个频道页必须有分页和至少两个子分类入口。
- 404 页面提供搜索、热门游戏和最新内容入口。

## 6. 内容丰富度基线

- 首页 30–45 个可点击内容入口。
- 一级频道首屏 8–12 个内容入口。
- 频道列表每页 18–25 条。
- 游戏中心 12–20 个内部内容入口。
- 每日首页至少出现 6 条 24 小时内更新内容。
- 同一个模块内避免超过 40% 内容来自同一游戏。

丰富度来自真实内容覆盖、分类和内链，不通过重复卡片、自动改写和无内容标签页凑数量。

## 7. 静态原型覆盖

静态原型提供以下独立页面：`index.html`、`games.html`、`rankings.html`、`new-games.html`、`guides.html`、`news.html`、`videos.html`、`codes.html`、`game.html`、`article.html` 和 `about.html`。

静态原型只验证结构和路径；生产页面数量与数据量以上线验收标准为准。
